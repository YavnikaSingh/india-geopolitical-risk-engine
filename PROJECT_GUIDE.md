# Project Guide — India Geopolitical Risk & Market Exposure Engine

## Overview
An exploratory research project examining how geopolitical shocks can transmit into India's economy, financial markets, supply chains, and exposed sectors.

## Research Framework
**Geopolitical event → Transmission channel → Economic indicator → Market/sector exposure → Scenario analysis → Analyst assessment**

## Project Files

| File | Purpose |
|---|---|
| `README.md` | Project overview, research question, findings, and dashboard |
| `METHODOLOGY.md` | Scoring framework, assumptions, and limitations |
| `ANALYSIS.md` | Interpretation of model outputs and transmission channels |
| `india_geopolitical_risk_engine.ipynb` | Python analysis, scenario comparison, and visualisations |
| `sql_analysis.sql.` | SQL queries for risk ranking, indicator changes, and scenario analysis |
| `india_geopolitical_risk_dashboard.png.png` | Power BI dashboard screenshot |
| `risk_scores_powerbi.csv` | Risk scores for Power BI |
| `indicator_changes_powerbi.csv` | Indicator percentage changes |
| `scenario_scores_powerbi.csv` | Baseline, escalation, and de-escalation scores |
| `sensitivity_powerbi.csv` | Scenario sensitivity and score increases |

## Analytical Components
- Geopolitical risk database and indicator mapping
- Analyst-defined quantitative risk scoring
- Baseline, escalation, and de-escalation scenarios
- Sensitivity analysis
- SQL-based analytical queries
- Python analysis using pandas and Matplotlib
- Power BI dashboard

## Important Limitations
This is an exploratory research prototype, not a forecasting or probability model. Scores, weights, and scenario assumptions are analyst-defined. Some indicator observations require further source verification, and the freight-cost series is illustrative rather than observed market data.
